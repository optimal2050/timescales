# Core timeframe identifiers

Standard timeframe names used for datetime component extraction. These
correspond to hierarchical time divisions from years down to seconds,
plus week-related axes.

## Usage

``` r
CORE_TIMEFRAMES
```

## Format

Character vector of timeframe names.

## Value

A character vector of the core timeframe names.

## Examples

``` r
CORE_TIMEFRAMES
#>  [1] "YEAR"     "QUARTER"  "MONTH"    "MDAY"     "YDAY"     "HOUR"    
#>  [7] "MINUTE"   "SECOND"   "WDAY"     "WHOUR"    "MWEEK"    "WEEK"    
#> [13] "SEASON"   "DAYTYPE"  "HOURTYPE"
```
